⚙️ Firebase 設定指引

只需要做一次，約 5 分鐘。完成後所有裝置都能同步。

1
建立 Firebase 專案

前往 console.firebase.google.com，點「新增專案」，取個名字（例如：my-furniture），關閉 Google Analytics，建立完成。

2
啟用 Firestore 資料庫

左側選單 → 建構 → Firestore Database → 建立資料庫 → 選「正式版模式」→ 選亞洲地區（asia-east1）→ 完成。

3
設定安全性規則

Firestore → 規則 → 把規則改成下面這樣，然後發布：

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId}/{document=**} { allow read, write: if request.auth != null && request.auth.uid == userId; } } }
4
啟用 Google 登入

左側 → 建構 → Authentication → 開始使用 → Sign-in method → Google → 啟用 → 填入專案公開名稱 → 儲存。

5
